# Working with Claude

First presentation in the advisory material accompanying [Architecting with Claude](https://andrewphunter.com/writing/architecting-with-claude/).

Status: prepared for the advisory site, with PDF and PowerPoint downloads. All slides include the approved speaker notes in PowerPoint.

The 14-slide sequence adapts Andrew's work training, *Review the Harness, Not the Lines*. The approved blog article governs the refined guidance on cooperative planning, concise instructions, independent review, and meaningful verification.

## Files

- `output/working-with-claude-v1.pptx`: editable presentation with facilitator notes and source links.
- `output/working-with-claude-v1.pdf`: slide-only reading copy.
- `source/build.mjs`: editable content and layout source.
- `source/notes.md`: presenter notes, written as the explanation accompanying each slide.
- `source/slides.md`: generated text and facilitator notes for editorial review.

Examples are illustrative and need the commands and conventions of the receiving repository. The settings shown are excerpts, not a complete security configuration. The deck contains no internal company names, repository counts, channels, or policy material from the work training.

The first pass uses the advisory site's existing artwork, colors, and IBM Plex fonts. Detailed architecture and testing material remain separate presentations. No demo repository is required.
